# Моделювання та аналіз вимог до програмного забезпечення

Лабораторні роботи Кузнецова Кирила Олексійовича, група ІМ-о51.

## Завдання 1 - Прокат туристичного спорядження

Тема роботи - сервіс прокату "Споряджай". Клієнт може взяти намет, рюкзак або спальник на певний строк. В одній оренді може бути кілька предметів, які повертають окремо.

У каталозі є типи спорядження та конкретні предмети. Наприклад, два однакові намети мають спільний опис, але різні інвентарні коди. Для кожного орендованого предмета зберігаються погоджена ціна за добу та час повернення.

Перевірку роботи варто почати з [DEFENSE.md](Labs/lab-1/DEFENSE.md).

- [spec.md](Labs/lab-1/spec.md) - що має бути у схемі та як перевірити результат.
- [model.mmd](Labs/lab-1/model.mmd) і [diagram.png](Labs/lab-1/diagram.png) - ER-модель та її зображення.
- [ai/prompts.md](Labs/lab-1/ai/prompts.md) - запити, умова початкової чернетки та фідбек перевірки.
- [ADR](Labs/lab-1/adr/0001-rental-data-model.md) - які варіанти розглянуто й чому обрано цю модель.

Роботу виконано з використанням ШІ. У моделі 7 сутностей і 6 зв'язків. Три розбіжності початкової версії розглянуто в DEFENSE й виправлено одним оновленням.
